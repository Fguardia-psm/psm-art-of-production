# The Art of Production

Interactive strategic campaign for insurance agents — based on PSM Brokerage’s *The Art of Production* manual.

**Live:** production deploys via Vercel on push to `main`.

## What it is

A recruiting + training experience that:

1. Scouts a **producer archetype**
2. Walks **five required campaigns** + **Nine Faces** master scene
3. Soft-gates the kit with **NPN** (licensed agent signal)
4. Unlocks **dossier, script pack, leader invite code**, and **Partner with PSM**

## Stack

TanStack Start · React 19 · Vite · Tailwind v4 · Zustand

## Develop

```bash
npm install
npm run dev      # 0.0.0.0:8080
npm run typecheck
npm run build
```
