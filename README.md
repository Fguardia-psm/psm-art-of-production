## What it is

A recruiting + training experience that:

1. Scouts a **producer archetype**
2. Walks **five required campaigns** + **Nine Faces** master scene  
3. Optional deep campaigns (Agency on the March, Intelligence)
4. Soft-gates the kit with **NPN** (licensed agent signal)
5. Unlocks **dossier, script pack, leader invite code**, and **Partner with PSM**

### Built for ~98/100 agent quality

- Field notes (not binary right/wrong only)
- Randomized Nine Faces choices + opening scripts
- Partner proof, support model, field-leader CTA with archetype
- Leader mode invite codes for downlines
- Downloadable script pack for Monday
